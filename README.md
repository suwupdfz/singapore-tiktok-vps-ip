## 为什么都盯新加坡，为什么 IP 类型比配置更影响账号

新加坡覆盖马来西亚、印尼、越南和整个东南亚受众，区域延迟低，国际 peering 条件好，出口位置不容易触发平台的地域怀疑。做东南亚内容，落地机放新加坡是常规操作。

真正决定账号表现的是 IP 所属的 ASN。TikTok 的风控体系会给接入 IP 打分，主机商自有的数据中心 ASN 评分偏差，住宅和原生商业宽带 IP 评分好。一台 4 核机器挂在被标记过的机房网段上，账号被限流的速度比一台 1 核机器配干净住宅 IP 还快。这也解释了为什么同样是 2 核 1GB，WePC 敢把住宅版卖贵一半。

原生 IP 和住宅 IP 的区别在这里：原生版给的是新加坡本地商业宽带属性的地址，住宅版给的是新加坡 ISP 的家庭宽带地址。前者适合让平台认为你是个正常在新加坡上网的用户，后者更适合需要"看起来就是一户人家"的场景，比如长时间直播、老号维护。

## 常见问题

**IP 会被 TikTok 识别为新加坡吗？**
原生 IP 和住宅 IP 的意义就在这里：平台看到的是新加坡本地网络属性，不是机房地址。但账号会不会被限流，还取决于内容、操作频率、登录设备、行为模式，没有哪家能打包票。IP 是必要条件，不是充分条件。

**能装 Windows 吗？**
现有资料只描述了 Linux 环境下的使用，没有提到 Windows 支持。需要 Windows 跑自动化工具的，下单前先问客服确认，别默认可以。

**支持哪些付款方式？**
PayPal、信用卡、支付宝都行。澳元结算，结账页可以切换人民币显示。

**住宅 IP 和原生 IP 到底差在哪？**
原生版是新加坡本地商业宽带属性的地址，住宅版是新加坡 ISP 的家庭宽带地址。前者适合内容发布和账号预热，后者适合长时间直播和老号维护。两者的硬件配置在 WePC 这里完全相同。

**年付中途想退怎么办？**
资料只覆盖了 3 天 / 10GB 的退款窗口，没有说明年付中途按比例退款的政策。按年付之前，先用月付把 IP 和账号表现验证掉。
